# Supervised Machine Learning Learning Path

This repository contains my hands-on practice notebooks while learning **Supervised Machine Learning**.  
The notebooks are organized in a progressive order — from basic EDA & preprocessing to regression, classification, hyperparameter tuning, and ensemble methods.

## Project Structure

| # | Notebook | Dataset | Focus |
|---|----------|---------|-------|
| 01 | `01_insurance_eda_preprocessing.ipynb` | Medical Insurance | EDA, Feature Encoding, Scaling |
| 02 | `02_heart_eda_preprocessing.ipynb` | Heart Disease | EDA, Encoding, Preprocessing |
| 03 | `03_ford_car_price_regression.ipynb` | Ford Car Prices | Linear Regression |
| 04 | `04_student_score_regression.ipynb` | Student Performance | Linear Regression |
| 05 | `05_titanic_classification.ipynb` | Titanic | Multiple Classifiers (LogReg, KNN, DT, NB, SVM) |
| 06 | `06_heart_disease_classification.ipynb` | Heart Disease | Classification + Model Saving |
| 07 | `07_titanic_cross_validation.ipynb` | Titanic | Cross-Validation |
| 08 | `08_iris_gridsearch_hyperparameter_tuning.ipynb` | Iris | GridSearchCV (KNN & SVM) |
| 09 | `09_iris_ensemble_learning.ipynb` | Iris | Stacking, AdaBoost, Gradient Boosting, XGBoost |

## Technologies Used

- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- XGBoost

## Learning Path Overview

1. **Data Understanding & Preprocessing** (Notebooks 01–02)
2. **Regression Problems** (Notebooks 03–04)
3. **Classification Problems** (Notebooks 05–06)
4. **Model Evaluation & Cross-Validation** (Notebook 07)
5. **Hyperparameter Tuning** (Notebook 08)
6. **Ensemble Learning** (Notebook 09)
